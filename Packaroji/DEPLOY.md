# Deploy Packaroji v33

This version is based on Packaroji v32 and adds only the temporary emoji cursor feature.

- Back / shop actions: 🥹 cursor for about 1.8s, or until mouse movement.
- Successful add-to-cart: 😁 cursor.
- Successful checkout/order: 😁 cursor on the successful order-detail redirect.
- Touch/mobile devices: no custom cursor behavior.

Deploy this folder/package using the same Render settings as v32.
After deployment, hard refresh with Ctrl+Shift+R.
